## 一、照着做（产品经理接口验证步骤）

1. 启动后端（终端）：

```bash
cd apps/ifplay-backend
uv sync                                   # 首次安装依赖
uv run uvicorn app.main:app --port 8000
```

看到 `Application startup complete.` 即成功。

2. 健康检查（新终端）：

```bash
curl -s http://127.0.0.1:8000/api/v1/health
```

看到 `{"status":"ok",...,"provider_is_real_model":false}` 即成功（false = 非真实模型）。

3. 创建创作会话并走完澄清（记下 `session_id`）：

```bash
curl -s -X POST http://127.0.0.1:8000/api/v1/sessions \
  -H 'Content-Type: application/json' -d '{"idea":"开一家深夜食堂，经营小餐馆"}'
```

4. 提交两次澄清答案（把 `<sid>` 换成 session_id）：

```bash
curl -s -X POST http://127.0.0.1:8000/api/v1/sessions/<sid>/clarifications \
  -H 'Content-Type: application/json' -d '{"answer":"赚钱并升级"}'
curl -s -X POST http://127.0.0.1:8000/api/v1/sessions/<sid>/clarifications \
  -H 'Content-Type: application/json' -d '{"answer":"一局约5分钟"}'
```

5. 查看方案卡（应含 8 个补充字段：estimated_minutes / resources / fail_conditions / progression / visual_direction / asset_plan / limitations / track_reason）：

```bash
curl -s http://127.0.0.1:8000/api/v1/sessions/<sid>/plan
```

6. 修改方案（旧方案保留）并查看历史：

```bash
curl -s -X POST http://127.0.0.1:8000/api/v1/sessions/<sid>/plan/modify \
  -H 'Content-Type: application/json' -d '{"request_text":"名字更有吸引力"}'
curl -s http://127.0.0.1:8000/api/v1/sessions/<sid>/plans   # 应返回 2 条方案记录
```

7. 确认方案、创建生成任务、查询结果：

```bash
curl -s -X POST http://127.0.0.1:8000/api/v1/sessions/<sid>/plan/confirm
curl -s -X POST http://127.0.0.1:8000/api/v1/sessions/<sid>/tasks \
  -H 'Content-Type: application/json' -d '{"idempotency_key":"demo-1"}'
```

稍等 1～2 秒后查询（记下 `task_id` 与 `version_id`）：

```bash
curl -s http://127.0.0.1:8000/api/v1/tasks/<task_id>          # 应为 playable
curl -s http://127.0.0.1:8000/api/v1/tasks/<task_id>/result    # usage 里应有 clarification/plan/gamebundle 用途
```

8. 自然语言修改（异步入队，记下修改任务 `task_id`）：

```bash
curl -s -X POST http://127.0.0.1:8000/api/v1/sessions/<sid>/versions/<version_id>/modifications \
  -H 'Content-Type: application/json' -d '{"request_text":"把回合数改成20","idempotency_key":"m1"}'
```

稍等后查询（应 succeeded，新版本 `parent_version_id` 指向原版本）：

```bash
curl -s http://127.0.0.1:8000/api/v1/modifications/<修改task_id>/result
```

9. 查看版本列表（默认仅最近 N 个可玩版本；`include_archived=true` 看全部）：

```bash
curl -s http://127.0.0.1:8000/api/v1/sessions/<sid>/versions
```
