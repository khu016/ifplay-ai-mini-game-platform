# IfPlay M1.1A 游戏深度增强 验收步骤

## 准备

1. 在 `apps/ifplay-m0/` 执行 `npm install`、`npm run dev`。
2. 浏览器打开 `http://localhost:5173/`。
3. 手机竖屏：DevTools 切手机模式，宽度 `390`、高度 `844`。

## 一、拖拽合成《把老板画的饼拖进微波炉炼成年终奖》

1. 打开后能看到：上方得分/步骤/连击，中间**微波炉两格**，下方**可拖物品**（大饼/鸡血/情怀/空头支票/保温杯），右侧**订单**和**图鉴**。
2. 把「大饼」拖进左格、「鸡血」拖进右格 → 合成「年终奖雏形」（图鉴出现 ✓）。
3. 把「年终奖雏形」拖进左格、「情怀」拖进右格 → 合成「年终奖」。
4. 把「保温杯」拖进左格、「情怀」拖进右格 → 合成「养生大师」。
5. 点订单上的「交付」按钮，交付「年终奖」和「养生大师」→ **成功结局**（年终奖到手）。
   - 另一条路线：大饼+空头支票→更大的饼，更大的饼+鸡血→年终奖。
6. 把两张「空头支票」分别拖进两格 → 触发「跑路计划」（隐藏 flag），之后游戏自然结束时结算为**隐藏结局「卷款跑路」**。
7. 合成失败时，提示区会给出「糊了」+ 图鉴提示。

## 二、点击时机《在公司厕所偷偷修仙》

1. 打开后能看到：上方**阶段 1/3**、连击、判定；中间三条进度（灵气/憋气/暴露度）；绿色安全窗口 + 移动光标。
2. 在绿色窗口内点击 → 灵气上升、连击增加；点空 → 暴露度上升。
3. 长按不放 → 灵气缓慢上涨，但**憋气下降**；憋气耗尽会暴露度上升（风险）。
4. 灵气攒满第一阶段 → 自动进入**阶段 2**，解锁技能「清心咒」；阶段 2 满 → 阶段 3，解锁「回气诀」。
5. 点技能按钮使用（一次性），可清暴露度/回憋气。
6. 闯过三阶段 → **小周天圆满**，结算给出 S/A/B/C 评价。
7. 暴露度爆表 → **被老板发现**，并显示失败原因与改进建议。

## 三、通用

- 存档：任意游戏操作几步 → 点「存档」→ 刷新 → 重新进入 → 状态恢复。
- 暂停/继续/重新开始均可用。
- 四款游戏（含经营模拟、剧情问答）都能打开并推进（M0/M1 回归）。
