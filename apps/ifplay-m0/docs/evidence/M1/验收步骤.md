# IfPlay M1 验收步骤（照着做）

## 准备

1. 在 `apps/ifplay-m0/` 目录执行：`npm install`、`npm run dev`。
2. 浏览器打开 `http://localhost:5173/`。
3. 手机竖屏：打开浏览器开发者工具（DevTools），切到手机模拟，宽度设为 `390`、高度 `844`（iPhone 尺寸）。

## 第一步：选择页

- 应看到 **4 张游戏卡**，每张卡带玩法类型标签（经营模拟 / 点击时机 / 拖拽合成 / 剧情问答）。

## 第二步：逐款试玩（每款至少走到一个结局）

### 1. 经营模拟《我在三线城市给外星人修手机》
- 点「接待」接待顾客 → 选对零件 → 资金、口碑上升。
- 点「结束本回合」推进天数；经营到第 12 天 → 「站稳脚跟」（成功）。
- 一直不服务、只结束回合 → 口碑耗尽 → 「差评倒闭」（失败）。

### 2. 点击时机《在公司厕所偷偷修仙》
- 在绿色安全窗口内点击运气 → 灵气上升、连击增加。
- 攒满灵气 → 「小周天圆满」（成功）；一直点空 → 暴露度爆表 → 「被老板发现」（失败）。

### 3. 拖拽合成《把老板画的饼拖进微波炉炼成年终奖》
- 把「大饼」拖进左格、「鸡血」拖进右格 → 合成「年终奖」。
- 凑够 150 分 → 「年终奖到手」（成功）。
- 把两张「空头支票」分别拖进两格 → 「卷款跑路」（隐藏结局）。

### 4. 剧情问答《凌晨三点在业主群竞选小区龙王》
- 一路做选择，积累威望。
- 投票时威望 ≥ 3 → 「高票当选」（成功）；威望不足 → 「竞选失败」（失败）。
- 开局选「晒出龙王转世截图」，投票时「亮出转世证明」→ 「龙王转世」（隐藏结局）。

## 第三步：存档与恢复

- 在任意游戏里操作几步 → 点「存档」。
- 刷新页面 → 重新进入同一游戏 → 状态应恢复（如经营模拟的「天数」不归零）。

## 第四步：控制项

- 每款游戏：点「暂停」→ 状态不再变化；点「继续」→ 恢复；点「重新开始」→ 回到初始。
