## 一、交付内容

纯 TypeScript 单包 `game/`，实现确定性 GameSpec 规则引擎（无后端、无数据库、零模型调用）：

- `schema/`：GameSpec v0.1 类型定义 + JSON Schema 工件。
- `validate/`：结构校验、引用完整性、数值边界（min/max、weight、cooldown、枚举、重复 id）。
- `engine/`：回合循环、条件求值、效果执行、结局优先级、seedable PRNG（mulberry32）、存档序列化。
- `simulate/`：自动路径模拟、死局检测、资源越界检测、结局可达性分析。
- `ui/`：最简试玩页（引擎逻辑与界面分离），localStorage 存档/读档。
- `samples/`：3 个手写 GameSpec（原创荒诞风格）。

## 四、照着点步骤（产品经理验收）

1. 终端进入 `docs/阶段文档/IfPlay开发/game/`，执行 `npm run dev`。
2. 浏览器打开 `http://localhost:5173/`。
3. 首页应显示三个示例游戏卡，点任一「开始游戏」。
4. 试玩页上方显示回合与种子、数值条；下方显示事件卡与选项按钮。
5. 点选项推进几回合，观察数值变化；可点「存档」再「读档」验证恢复。
6. 玩到出现「结局：xxx」卡片即完成一轮；点「重新开始」或「返回菜单」。

## 五、已知限制

- 自动路径模拟只用了 3 种粗策略（first/last/random）；部分失败/隐藏结局需特定玩法路径（如"身份暴露"需在不拖垮好评的前提下拉高暴露度），自动随机未覆盖，属预期而非引擎缺陷。手工试玩可验证。
- 试玩页为最简功能页，无视觉设计；正式前端留待阶段 3。
- 无后端、无数据库：存档仅本机 localStorage，不跨设备。
- 未做真机移动端宽度检查（样式为响应式 max-width 640px）。
- 未配置 Lint（仅 `tsc` 严格模式 + `noUnusedLocals/Parameters`）。
