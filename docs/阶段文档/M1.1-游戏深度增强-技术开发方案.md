## 3. 拖拽合成增强（`drag-merge`）

新增配置（均可选，缺省回退旧行为）：

- `supply`：`{ pool:[{itemId,weight}], initialDraw, restockEvery, restockCount }` —— 固定 seed 补给池，开局抽取 + 每 N 步定期补充。
- `recipes[].output`：`{ itemId, count }` —— 合成产物回流库存，支持两级/三级合成链。
- `orders`：`[{ id, name, targetItemId, deadlineStep, reward }]` —— 多张限时订单 + 中间目标。
- `goal`：`{ type: 'ordersFulfilled' | 'score', value }` —— 胜利条件（订单数或分数）。
- `recipes[].hint`：合成失败时给出可学习的提示。

新增机制：

- 订单：把目标产物「交付」给未过期订单，累计奖励；订单目标可配置多条路线（≥2 条有效完成路线）。
- 图鉴：`discovered` 记录已发现配方；UI 显示已发现/未发现（未发现显示 `???` + hint）。
- 失败反馈：合成失败时根据提示给出「试试别的组合」类反馈。
- 隐藏结局在**自然结局之后**结算（flag 覆盖），避免开局/中途误触发。
- 最佳成绩 + 游玩次数统计。

## 4. 点击时机增强（`timing`）

新增配置（均可选，缺省回退旧行为）：

- `stages`：`[{ cycleMs, windowWidth, jitter, targetSpirit }]` —— 三个逐步变难阶段（速度/窗口/抖动逐级配置）。
- `hold`：`{ slowFactor, spiritGainPerMs, breathDrainPerMs }` —— 长按有明确收益（攒灵气）同时消耗憋气、憋尽加暴露（风险），避免无脑长按。
- `exposureRecoverPerMs`：暴露度随时间自然恢复。
- `skills`：`[{ id, name, desc, stageIndex, effect }]` —— 达成阶段目标解锁一次性技能（清暴露/加灵气/回憋气）。
- `rating`：`{ s, a, b, c }` —— S/A/B/C 结算评价阈值。
- 失败时输出具体原因 + 改进建议。

新增机制：三阶段推进、阶段解锁技能、评价等级、最佳成绩、约 3 分钟时长（由配置控制）。

## 5. 数据与兼容

- 模块契约新增可选 `scoreOf(state): number`，运行时在 `game:ended` 时写入最佳成绩统计。

- 统计存储：`loadStats/saveStats`（`core/stats.ts`），失败也计一次游玩。
