# 人格会议网页端 · 项目专属约束

> 本文件在外层 `AGENTS.md`（核心规则卡）之上，补充本项目专属约定。冲突时以外层核心规则卡为准。

## 产品边界（来自 PRD v1.1，已确认部分）
- 形态：首版为响应式网页，适配手机和电脑浏览器；微信小程序留待后续版本。
- 用户：18 岁以上；首批为学生和年轻职场人。
- 核心闭环：输入问题 → 选 3–5 个人格角色 → 开放式讨论（首轮后暂停、每次一个有限单元）→ 用户主动结束 → 决策纪要。
- 登录：网页账户方式（待选邮箱/手机号/第三方），阶段 0 确认；年龄确认必须年满 18 岁。
- 角色：直接使用 INTJ/ENFP 等四字母类型作为 AI 创作的角色，不是官方 MBTI 测评，不代表真实专家，不判断用户人格、心理或命运。
- 高风险（自伤危机、医疗诊断、法律结论、高风险投资等）：停止角色讨论，转入安全引导；危机联系方式必须按上线地区核验，不得让模型现编。

## 强制底线补充（本项目特有）
- 人格角色不得声称「用户就是某种人格」、不得用于招聘筛选/能力评价/心理诊断。
- 不得复制 Myers-Briggs / 16Personalities 等第三方的专有测试题、插画、角色形象和文案；公开名称、宣传文案、视觉资产上线前做商标与知识产权审查。
- 会议自动保存 + 用户只能看自己的数据 + 可删除；删除后不得继续出现在历史列表或模型记忆中。
- 浏览器代码不得包含登录服务密钥或模型密钥；权限判断在后端。
- 模型只发当前步骤所需上下文；默认日志不记录完整问题原文。

## 状态约定
- 会议状态机：`新建 → 风险检查 → 角色确认 → 主持人澄清 → 首轮生成 → 等待用户 → 讨论单元生成 → 等待用户 → 纪要生成 → 已结束`，辅助状态含 `生成中、暂停、失败、安全中止、已删除`。
- 宿主程序管状态、最大轮次、预算、权限和事实版本；模型只负责当前步骤内容，不得自行改状态或授权。

## 当前授权范围
- 仅处于阶段 0 PRD 体检；未授权任何开发。进入后续阶段须产品经理确认。
