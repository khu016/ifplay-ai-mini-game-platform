## 二、验证结果

### 第一层：mock 自动化测试（通过 25 / 25）

- 登录与年龄确认：未满 18 / 未确认禁止进入；验证码错误/过期/邮箱格式。
- 风险检查规则：自伤、医疗、法律、高风险财务分别命中中止；普通问题不误伤。
- 状态机流转：非法跳转被拒；结束必须经过纪要生成。
- 角色发言解析器：标准 JSON、markdown 围栏、中文键、自由文本回退。
- 纪要结构校验、保存/历史/删除/跨用户隔离（目标零）、条件更新、SSE 以 done 收尾。

### 第二层：mock 端到端冒烟（通过）

用 curl + 真实浏览器走通完整链路：登录 → 年龄确认 → 推荐 4 角色 → 创建会议 → 开始（主持人 + 首轮 4 发言）→ 继续（SSE 流式）→ 补充条件（新事实版本）→ 生成纪要（5 类信息）→ 历史列表。

### 数据可恢复（通过，已实测）

停止服务后重启，会议列表仍完整保留（`data/app.db` 持久化）。

### 桌面与移动端宽度（通过）

桌面 720px、移动 390px 均无横向溢出（`03-mobile.png` 中 scrollWidth = 390 = 视口宽）。

### 密钥与隐私（通过）

无真实密钥；`.env`/`.venv`/`data/`/`__pycache__` 均已 gitignore；日志不记录问题原文。

## 三、真实模型冒烟（待验）

本项目尚未配置 API Key（D4 已定国内厂商，Key 由产品经理验收前提供）。届时需验证：真实模型输出质量、结构化输出成功率、首字延迟、SSE 收尾、以及 5–10 条真实样例打分（D2「待样例打分」→ 落 D2/D3）。**当前不得以 mock 结果冒充真实验证。**
