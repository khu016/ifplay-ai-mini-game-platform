# 氢能项目专属规则

继承外层工具包 AGENTS.md 的安全与验收底线。用户最新指令优先。

1. 用户已授权先输出第一子阶段技术手册，再开发后端创建报告、提取项目信息和九章大纲；只推进本子阶段，后续先确认。
2. 获准恢复后，只做创建报告、提取项目信息、生成九章大纲。完成这一步后停止交付验收；后续功能先询问用户。
3. 所有氢能业务代码、PRD、阶段文档、证据、依赖与本地配置放在本项目目录；本目录是业务路径解析的根。
4. `.env` 属于氢能 Agent，不与其他 Agent 共享，不从外层仓库加载配置，不输出密钥正文。
5. 保留现有代码与测试草稿，不宣称已运行或完成；恢复开发先检查路径搬迁、依赖锁定与现有实现风险。
6. 只使用脱敏/公开资料；任务全生命周期预算 1 元，月预算 100 元。真实调用前核查最新官方人民币费率与账户结算条件。
7. 文档、状态和证据统一保存在本项目 `docs/`；外层 `docs/项目状态.md` 只作为项目导航与当前状态摘要。
