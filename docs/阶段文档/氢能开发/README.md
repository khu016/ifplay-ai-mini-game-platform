# 氢能可研报告生成助手

这是氢能 Agent 的独立项目目录。项目文件路径均以本目录为基准，不以外层工具包根目录为基准。

**当前只整理文件与编写开发文档，暂停开发。已有代码是未运行测试的草稿，不代表功能完成。**

## 配置边界
- DeepSeek 配置只属于氢能 Agent；不得从外层工具包 `.env` 或其他 Agent 项目隐式读取。
- 当前没有实际 `.env` 或 `.ena`，不能声称已保存 API Key。`.env.example` 只是模板。
- 未来其他 Agent 使用自己的项目目录、`.env`、依赖和数据目录；每个项目单独维护配置。
- 当前沿用外层 Git 仓库，本目录未初始化嵌套 Git 仓库。“独立项目目录”不等于已经拆成独立 Git 仓库。

后续开发须用户明确确认；运行与真实验收方法以第一步开发文档中的计划为准，尚未实际验证。
