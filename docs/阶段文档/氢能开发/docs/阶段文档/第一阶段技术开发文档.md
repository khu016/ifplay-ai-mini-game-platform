# 第一阶段技术开发文档

> 历史草稿，保留用于追溯。2026-09-15 用户要求暂停开发，当前说明以 [第一步开发文档](第一步开发文档.md) 为准；本文不能作为继续开发授权。项目路径以“氢能开发”目录为根。

## 目标与范围
本机单用户任务创建 → 信息提取 → 流式九章大纲 → 保存 JSON 与 Markdown。仅脱敏/公开输入。无正文、Word 导出、正式网页、上传、知识库、角色或云部署。

## 技术与配置
Python 3.12、FastAPI、Pydantic、httpx（直接调用已核查的 DeepSeek 兼容 REST API）、pytest、ruff。依赖通过项目内 uv 安装与锁定。模型 `deepseek-flash`，非思考模式，配置见 `.env.example`；API Key 由用户填入 `.env`，不读取输出密钥。绑定 127.0.0.1:8765，单进程。

## 数据与恢复
`data/tasks/<UUID>.json` schema_version=1：描述、名称、时间、状态、项目信息、版本列表、最近错误及调用次数。原子写入并 fsync；本地文件锁限定单进程运行并保护读写。损坏文件统一报错，不覆盖；旧有效版本永久保留，无自动清理。
状态：created → extracting → generating → ready；调用失败为 error；服务中断的 extracting/generating 在下次启动变为 interrupted，用户显式重试。未完成的模型输出不是有效版本。队列不自动重新付费执行。
独立预算账本记录年月、任务、预留与结算；先持久化最大费用预留再调用。缺失 token 用量、断流或中断时保持保守预留，不能重启绕过上限。

## 接口与入口
统一错误 `{"error":{"code":"...","message":"..."}}`，不展示输入、密钥或堆栈。
| 方法/路径 | 请求 | 响应 |
| --- | --- | --- |
| GET /health | 无 | status、model、key_configured（仅布尔值） |
| POST /api/v1/tasks | description: 10—4000 字符；name: 可选，1—120 字符 | Task schema，201 |
| GET /api/v1/tasks/{id} | UUID | Task schema |
| POST /api/v1/tasks/{id}/outline | 无请求体 | SSE：chunk{stage,text}，done{task} 或 error{error} |
| GET /api/v1/tasks/{id}/outline.md | UUID | 当前有效 Markdown，大纲未就绪返回统一错误 |
| GET /api/v1/tasks/{id}/outline.json | UUID | 当前有效 Outline schema |
| GET /api/v1/budget | 无 | 月累计、剩余额度、估价配置是否确认 |

错误包括 INVALID_REQUEST、NOT_FOUND、TASK_BUSY、MISSING_KEY、PRICING_UNCONFIRMED、BUDGET_EXCEEDED、MODEL_AUTH、MODEL_TIMEOUT、MODEL_FAILED、INVALID_MODEL_OUTPUT、STORAGE_CORRUPT、STORAGE_FAILED、OUTLINE_NOT_READY。
CLI 读取本地描述文件，由执行者代跑，输出任务 ID 与大纲文件位置，不打印完整输入或密钥；实际收费通过显式 generate 操作触发，不在启动时调用模型。

## Prompt 与校验
独立信息提取和大纲 Prompt 文件。字段 null 表示缺失，大纲包含待补充条目。仅生成大纲，不生成未经依据的事实结论。JSON Object 模式；Pydantic 校验恰好九章、顺序 1—9 与每章 3—5 子标题。候选不合规不得成为已通过产物；数量超标记录错误给用户，不自动重试烧钱。网络暂时失败可有限重试，每次受预算约束；认证与内容质量失败不自动重试。

## 预算
上限为任务生命周期 1 元（信息提取、大纲和所有重试），自然月 100 元。官方公布美元计价，真实调用前须明确账户单价与换算依据。默认不确认估价，禁止收费调用；不可把名义汇率当作当前官方汇率。每次按最大输入保守 token 界和最大输出预留，结算不得超过预留；异常时保留预留并阻止继续使用不可信估价。价格变化须更新配置后再调用。

## 测试与验收
mock 检查 API 错误脱敏、正确九章、数量违规不重试、断流收尾、超时/认证失败、并发拒绝、预算预留跨重启、旧版本保留、损坏文件及路径安全；子进程实际重启检查持久化任务恢复。
真实检查：5—10 条脱敏/公开样例，经 DeepSeek 两类契约生成并保留大纲；记录首 chunk、总耗时、token 和费用，用户评分。大纲性能目标来自 PRD（首字符 <5 秒、整体 <30 秒），未达到则如实列为未通过。
验收：在 IDE 打开生成的大纲 Markdown 预览，核对九章、子标题与待补充内容；重启后打开同一任务；真实评分标准未冻结前不宣布阶段完成。

## 风险与交接
文件锁支持单进程本机使用；多用户/并发写入须重新适配数据库。公开资料授权不涵盖内部文档。API Key 和账户计价尚待本地配置，真实效果待验。后续复用任务、项目信息和有效九章结构，不提前实现正文。
