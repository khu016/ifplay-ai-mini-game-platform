## 1. 产品形态判断
- 氢能研究员输入脱敏或公开项目描述，保存任务，提取项目信息并生成九章大纲。
- 开发路径：后端先行，遵循 PRD 前三个产品阶段以文件验收的分期。
- 当前范围：项目阶段 2 后端 MVP / 产品阶段一；产物为可阅读 Markdown 大纲、结构化 JSON 与本地持久化任务。
- 仅本机单用户运行。正式大纲编辑/确认网页与后续正文排队不在本阶段；本阶段可通过打开 Markdown 预览人工评价大纲，不以 JSON 或测试结果替代质量验收。

## 2. 采用的默认方案
- Python 3.12 独立 `.venv`、FastAPI、Pydantic、pytest。当前默认 Python 为 3.9.6，开发前准备 3.12，不更改系统版本。
- 通过 DeepSeek 官方兼容接口调用其服务，密钥从被 Git 忽略的 `.env` 读取；不要求用户安装开发依赖或创建目录。
- 推荐模型 `deepseek-flash`，先使用非思考模式，减少大纲任务的延迟与额外输出；是否达到性能与专业质量要求以真实调用为准，不预先承诺。
- 2026-09-15 已核查 [官方接入文档](https://api-docs.deepseek.com/)、[模型与价格](https://api-docs.deepseek.com/quick_start/pricing/)及 [JSON Output](https://api-docs.deepseek.com/guides/json_mode/)。官方当前列出 Flash 与 V4 Pro，支持 JSON Output；不使用未经核查的旧模型名称。
- JSON Output 仍须本地结构校验，处理空输出和截断，强制恰好九章及每章 3—5 个子标题，不将格式合法视为事实正确。

## 3. 触发的按需模块
- 本机单用户简单任务：带 schema 版本的文件清单、原子写入与每任务独立目录；暂不引入关系数据库或外部队列。保存输入、提取结果、大纲版本与调用状态；中断任务可恢复并明确提示重试。
- 大纲流式反馈：SSE，由后端转换模型流，终止必须输出 done 或 error；仅在完整校验后将候选大纲设为有效版本。
- 成本记录：本地持久化调用次数、token 用量、估算费用与月累计。每次信息提取、大纲与重试均计入同一任务上限；有限重试前预留预算，不能通过拆分调用绕过上限。
- 本阶段无 RAG、PDF/Word 解析、向量库或 Word 导出模块。

## 4. 偏离或暂缓
- 正式前端与临时网页均暂缓，按用户确认的文件验收范围提供 Markdown 预览和执行者代跑；正式网页在产品第四阶段重新评估。无需当前 Node 升降级。
- 登录、权限、云端与企业认证暂缓，不开放远程访问。
- 全文指标、跨章一致性、知识库共享与页码定位在对应阶段前裁决，不能以模型自身知识冒充有依据的报告。
- 无新增云平台、云资源费用或产品功能范围；本机依赖与所选 DeepSeek API 在既定预算内准备。

## 5. 强制底线与验证计划
- 密钥与隐私：方案明确，实施待验；仅发送获准的脱敏/公开信息，日志不记完整输入。
- 恢复：方案明确，实施后须实际重启验证；保留有效大纲版本，不以失败候选覆盖。
- 校验：接口请求、响应、模型 JSON 全部校验；缺参数显示待补充。
- 错误：统一 `error.code` 与 `error.message`，不回显堆栈或敏感内容；超时、初始化失败与有限重试均有兜底。
- 验证：有意义的 mock 测试覆盖结构、失败、重试、预算及恢复；另做 5—10 条真实样例，用户打分；无真实调用不宣布模型验证完成。
- 费用：官方目前以美元公布 token 单价，不能直接当作人民币单价。真实调用前按账户结算条件与明确换算参数核算保守上界，保持每任务 1 元、每月 100 元限制。若无法可靠估算或额度不足，阻止调用并反馈。尚未充值、创建云资源或进行收费调用。
