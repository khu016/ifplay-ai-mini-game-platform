## 固定约定
- 氢能 Agent 只用自己目录内的 `.env`；当前只有 `.env.example`，未发现实际 `.env` 或 `.ena`。
- 其他 Agent 不共享氢能 Key，不在外层根目录散放业务代码和配置。
- 当前仍是一个 Git 仓库下的独立项目目录，尚未创建嵌套 Git 仓库。
- 开始任何工作先读相应项目目录的 AGENTS.md 与项目状态，不重复询问已记入台账的决定。
