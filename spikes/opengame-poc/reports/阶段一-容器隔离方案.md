# 阶段一 · 最小容器隔离方案（已安装并验证）

> 状态：Colima/Docker 已安装，基础隔离验证已通过（见 `阶段一-容器隔离验证报告.md`）。真实模型生成尚未开始。

## 1. 为什么需要容器

`sandbox-exec` 的 `allow default` 不禁文件读，生成代码可读宿主敏感文件并经日志外泄（见 `阶段一-隔离探针报告.md` 修正版）。容器提供内核级命名空间隔离，可按"白名单挂载 + 默认断网 + 资源限额 + 超时整体清理"执行生成/构建/测试。

## 2. 最小隔离设计（每款游戏一个专用容器）

- **只挂载单款游戏专用目录**：`-v <单款游戏目录>:/work:rw`，不挂载用户目录、其他仓库、`~/.ssh`、浏览器数据、宿主 `.env`。
- **根文件系统只读 + 临时 tmpfs**：`--read-only --tmpfs /tmp`，构建写盘仅落在 `/work`。
- **默认断网**：`--network none`；**构建与试玩阶段断网**。
- **生成阶段按白名单访问模型端点**：经供应商无关 egress 白名单代理（`runner/egress-proxy.mjs`），仅放行 `config/egress-allowlist.json` 登记的域名/端口，其余一律拒绝；默认全拒绝（未配置供应商时安全失败）。
- **资源限额**：`--cpus 2 --memory 2g --pids-limit 256`；磁盘受 VM 20G 上限约束（根只读 + tmpfs 限写范围）。
- **执行时间**：每一步（生成/构建/测试）设独立超时。
- **超时整体清理**：`docker run --rm` + 超时后 `docker kill` 整个容器，容器内全部子进程一并终止（容器即进程边界，不留孤儿进程）。

## 4. 启动 / 停止

```bash
colima start --cpu 2 --memory 4 --disk 20   # 测试时启动
# ... 隔离验证 ...
colima stop                                  # 测试完成停止（本轮已完成停止）
```

运行容器（示例）：
```bash
docker run --rm --network none --cpus 2 --memory 2g --pids-limit 256 \
  --read-only --tmpfs /tmp -v "$(pwd)/generated/<game>:/work:rw" \
  node:20-alpine sh -c 'cd /work && npm install && npm run build'
```

## 5. 卸载方式（如需）

```bash
colima stop && colima delete            # 删除 VM 与数据
brew uninstall colima docker lima       # 卸载二进制
rm -rf ~/.colima ~/.lima ~/.docker      # 清理配置/缓存
```
