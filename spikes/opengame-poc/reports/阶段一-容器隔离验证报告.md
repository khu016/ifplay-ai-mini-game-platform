# 阶段一 · 最小容器隔离验证报告

- 时间：2026-10-03
- 环境：Colima 0.10.3（macOS Virtualization.framework，aarch64）+ Docker CLI 29.8.2（Server 29.5.2）
- 镜像：`node:20-alpine`
- 可复跑脚本：`runner/verify-container-isolation.sh <单款游戏目录>`

## 结果（6 项全部通过）

| # | 验证项 | 结果 | 证据 |
| --- | --- | --- | --- |
| 1 | 默认断网 + 直连 IP/TCP | ✅ | `--network none`：DNS `Network unreachable`、直连 `1.1.1.1:80` → `BLOCKED:ENETUNREACH`、HTTP `bad address` |
| 2 | 无法读取宿主敏感目录 | ✅ | 仅挂载单游戏目录；容器内 `/Users`、`/root/.ssh`、宿主 `.env` 均为 `No such file or directory` |
| 3 | 无法写入挂载目录之外 | ✅ | `--read-only`：`/etc` 写 `Read-only file system`；仅 `/work`（挂载）与 `/tmp`（tmpfs 临时）可写 |
| 4 | 超时后整个进程树终止 + 容器删除 | ✅ | 容器内进程树 5 节点（sleep/sh 父子孙）；`docker kill` 后残留容器 = 0（`--rm` 自动删除） |
| 5 | 容器内真实构建 | ✅ | `npm install` + `npm run build` 成功，退出码 0，产出 `dist/index.html` + `build-info.json` |
| 6 | 资源限额生效 | ✅ | `inspect`：CPU=2000000000（2 核）、MEM=2147483648（2GB）、PIDS=256、只读根=true、网络=none |
